# Пенальти — сцена для футбольного Telegram-бота

Страница Telegram Mini App: пенальти-дуэль бьющего и вратаря. Без параметров открывается демо
(соперник выбирает случайно). В матче бот открывает её со ссылкой на комнату, а исход считает сам бот.

Файл `index.html` копируется сюда из основного проекта (`webapp/penalty/index.html`) — правки делать там.

## Матч (match/)

Страница «📺 Смотреть матч»: живой матч на поле сверху, табло и лента комментатора; во время окна решений — панель решений менеджера (проверяет и применяет бот). Без параметров — демо со случайными событиями; в матче бот открывает её со ссылкой на комнату и сам присылает всё состояние. Исходник — `webapp/match/index.html` основного проекта.
